MIDNIGHT RUN — Pixel traffic survival

Version 1.2.0 — Combat update

HOW TO PLAY
Open index.html. It works locally in your desktop browser and is the Vercel deployment entry point.
No installation, server, account, or internet connection is required.

Enter / Space: start or restart
Arrow Left / Right: steer
Arrow Up: accelerate (higher score rate)
Arrow Down: brake
P / Escape: pause or resume
M: mute or unmute
F: full screen

Avoid traffic and survive. Passing close to a car earns a near-miss bonus.
Traffic gets faster and denser over time. Each traffic row leaves a lane open.
Best score is saved in your browser where local storage is available.
The game pauses when you leave its window.

Your supplied pixel-art image is embedded as the driver portrait.
Game graphics and audio are generated locally. No external assets are loaded.
Use a current desktop browser such as Edge, Chrome, or Firefox.

NEW COMBAT CONTROLS (v1.2.0)
A / D: steer left / right (arrow keys also work)
W: jump over traffic; protected from collisions for 1.1 seconds
Jump recharges 2.5 seconds after takeoff. Release W and press again.
S: brake (Down arrow also works)
Left-click inside the game: shoot toward the cursor
Destroyed cars award 150 points. Unlimited ammo; one shot per click.
Jump and bullets freeze while paused. Landing on traffic causes a crash.
